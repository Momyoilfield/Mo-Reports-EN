# Mo Global Oil Industry Reports (English Edition)

Publications of the Mo journal system (English edition): facts and general market analysis only. Mo's own operational content is in the internal Mo Briefing and is not published here.

Chinese edition: [Mo-Reports-CN](https://github.com/Momyoilfield/Mo-Reports-CN).

## Monthly — Mo Global Oil Industry Monthly Report

Published on the last calendar day of each month, 08:00 Beijing time. First half: upstream panorama; second half: downstream macro analysis.

- `monthly/2026-10-30/` — Inaugural Issue (English Word + PDF)

## Weekly — Mo Oil Industry Weekly Report

Published every Sunday, 20:00 Beijing time: production and rig changes, price trends, OPEC dynamics, the week's major events, outlook. First issue November 15, 2026.

## Sources

Each issue's appendix lists data sources and definitions. Different institutions report different numbers for the same thing because of different definitions, not errors; unavailable data is written as "no public data", never estimated or invented.
